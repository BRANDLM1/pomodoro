# README
Proposal and Specifications Document
Project Name: Pomodoro

Social Issue: Mental Health and academic burnout

Project Description (1 sentence)
An app engaging users in various guided focus sessions according to preferred themes and preferences to help structure focus sessions with a calming and encouraging interactive interface.

Impact
Project Pomodoro addresses this social issue through the positive psychological effects created  through the user experience. The application encourages healthy productivity and rewards the user for their performance. While there may be online videos with pomodoro timers or videos of other people studying, Project Pomodoro is an entire interactive user interface tracking focus cycles with customizable features, potential widgets and mental health resources.

Technical
Data Structures:  Hash/Dictionary for timer settings, timing state, and all theme sound and mood information, Array for tracking session progress.
New concepts: Audio integration, possible object animations, HAML or Slim,  ActiveRecord, HTML5, jQuery

Functionality: 
	Priority: Core timer functionality, theming system, progress tracking throughout session
	Additional: Advanced audio integration, achievement system, mental health resources
	Future Functionality: Productivity patterns, user history & accounts, ranking systems
